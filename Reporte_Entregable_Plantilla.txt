2. ARQUITECTURA Y DISEÑO DEL SISTEMA
--------------------------------------------------------------------------------
La arquitectura del proyecto está estructurada en dos capas independientes que se comunican a través de una API RESTful, promoviendo la escalabilidad y el mantenimiento del código.

### 2.1 Backend (Servidor)
- Lenguaje/Entorno: Node.js
- Framework: Express.js (para la creación y enrutamiento de la API)
- Base de Datos: SQLite (elegida por su portabilidad local sin requerir configuración de servidor externo en la etapa de desarrollo).
- ORM: Sequelize (garantiza operaciones CRUD eficientes y seguras contra inyecciones SQL).

Modelos de Datos Implementados:
- User (Usuarios): id, name, email.
- Project (Proyectos): id, title, description.
- Task (Tareas): id, title, description, status ('To Do', 'In Progress', 'Done'), projectId (relación 1:N con proyectos).

### 2.2 Frontend (Cliente)
- Librería Principal: React.js
- Herramienta de Construcción: Vite (para compilación ultra rápida).
- Enrutamiento: React Router (Navegación sin recarga de página o SPA).
- Estilos Visuales: Vanilla CSS. Se aplicó la tendencia de diseño "Glassmorphism" con variables CSS, asegurando una estética moderna, modo oscuro y diseño totalmente responsivo adaptado a la experiencia de usuario (UX).
- Comunicación HTTP: Axios.

4. INSTRUCCIONES DE DESPLIEGUE Y CONFIGURACIÓN
--------------------------------------------------------------------------------
A continuación, se describen los pasos para inicializar el proyecto en cualquier entorno de desarrollo local.

Paso 1: Inicialización del Backend
1. Abrir una terminal en el directorio `backend`.
2. Instalar dependencias mediante el gestor de paquetes: `npm install`
3. Iniciar el servidor: `node src/index.js`
4. Confirmación: La consola imprimirá "Database synced" y "Server is running on port 5000".

Paso 2: Inicialización del Frontend
1. Abrir una nueva terminal en el directorio `frontend`.
2. Instalar dependencias: `npm install`
3. Iniciar el entorno de desarrollo Vite: `npm run dev`
4. Confirmación: La aplicación estará accesible desde un navegador web en `http://localhost:5173`.

Despliegue en Producción (Estrategia Recomendada):
Para llevar la aplicación a un entorno en vivo, el código de React en el Frontend debe compilarse con `npm run build` y servirse como archivos estáticos en plataformas como Vercel o AWS S3. El Backend en Node.js debería alojarse en servicios como Render, Railway o AWS EC2, sustituyendo SQLite por una base de datos de producción como PostgreSQL.
